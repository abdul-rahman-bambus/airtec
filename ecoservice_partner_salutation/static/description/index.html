Partner Salutation - Custom Salutation for Every Title

Enhance your Odoo system with a feature that allows you to set custom salutations for every title. The module adds suitable salutations to standard titles and automatically updates German translations.

Key Features:

  • New field for complete salutation per title
  • Standard salutations:
    • Mr. Dear Sir,
    • Miss Dear Miss,
    • Mrs. Dear Madam,
  • Automatic creation and updates of German translations for Odoo standard titles
